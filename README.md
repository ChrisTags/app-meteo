## Objectif du projet

Ce projet d'application météo m'a permis de travailler sur la consommation d'API REST en mode asynchrone et sur l'intégration d'outils de cartographie interactifs.

### Réalisations techniques

- Connexion à une API météo pour récupérer et traiter des données climatiques dynamiques en temps réel.
- Intégration de l'API Google Maps pour afficher visuellement la localisation de la météo recherchée sur une carte interactive.
- Gestion complète des différents états de l'application : affichage du chargement, traitement des erreurs HTTP et validation des saisies utilisateur.
